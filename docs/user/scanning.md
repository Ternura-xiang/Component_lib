# 扫描入库

**扫描入库** 支持摄像头画面和从本机选择照片，主要识别电子元件袋贴上的文字及二维码/条码。

## 使用流程

1. 打开 **扫描入库**；可启动默认摄像头，或者选择一张标签照片。
2. 将标签置于取景引导区域，尽量避免反光、模糊、折痕遮住编号。
3. 查看识别结果、文字框及警告信息；核对立创编号、型号、封装、数量等字段。
4. 选择将草稿带到 **入库** 页面，再确认元件、数量与仓库，最后提交。

扫描页面不会直接写库存。低置信度或 OCR/二维码不一致时，更应该手动检查。

## 识别不准确时

先尝试重新拍照：光线均匀、字迹清晰、标签尽量正对镜头。摄像头不可用可以改用照片。注意识别功能依赖随程序安装的 OCR 模型；可以通过本机 API 的 `/health` 查看相关状态，开发者可参阅 [OCR 调试](../developer/recognition.md)。

识别出的订单号、物流字段或不确定的文字不应直接视为元件型号。保存纠错记录和 OCR 样本的功能用于改进规则，并不代表会自动训练模型。
