# 扫描入库

**入库 → 扫描 / 图片识别入库** 支持摄像头画面和从本机选择照片，主要识别电子元件袋贴上的文字及二维码/条码。

## 使用流程

1. 打开 **入库**，点击 **扫描 / 图片识别入库**；可启动摄像头，或者选择一张标签照片。
2. 将标签置于取景引导区域，尽量避免反光、模糊、折痕遮住编号。
3. 查看识别结果、文字框及警告信息；核对立创编号、型号、封装、数量等字段。
4. 选择将草稿带到 **入库** 页面，再确认元件、数量与仓库，最后提交。

扫描页面不会直接写库存。低置信度或 OCR/二维码不一致时，更应该手动检查。

## 识别不准确时

先尝试重新拍照：光线均匀、字迹清晰、标签尽量正对镜头。摄像头不可用可以改用照片。注意识别功能依赖随程序安装的 OCR 模型；可以通过本机 API 的 `/health` 查看相关状态，开发者可参阅 [OCR 调试](../developer/recognition.md)。

识别出的订单号、物流字段或不确定的文字不应直接视为元件型号，所有结果都需在入库表单中人工确认。

## 使用 Android 手机作为移动摄像头

1. 电脑打开 **设置 → 连接信息**，生成十分钟有效的配对二维码。
2. 手机安装移动端 APK，扫描电脑显示的二维码完成 HTTPS 配对。若扫到商品码或普通网址，手机会提示并继续取景，可以直接改扫配对码。
3. 在线手机会出现在摄像头下拉框中。设备正在入库、出库或取货时会显示当前操作，并暂不可选。删除设备后，重新使用时需要再次配对。
4. 在入库标签识别、批次扫码或扫码出库中选择“安卓 · 设备名”并打开摄像头，手机会自动进入对应拍照/扫码界面。
5. 手机拍照后由电脑执行 OCR，两端显示入库草稿。手机发起入库或出库时，电脑会在收到识别结果后打开对应页面。
6. 安卓出库可持续扫码。取景画面下方可修改数量并确认出库，批次、仓库色标及余量显示在同一页面。任一端确认后，另一端会更新结果。

手机与电脑必须位于同一局域网，且桌面程序保持运行。手机断网时不会离线保存或补交库存操作。
关闭摄像头或在电脑上退出对应入库、出库页面会结束共享会话。未处理的远程摄像头请求会在两分钟后清理。详见[安卓说明](../../android/README.md)。
