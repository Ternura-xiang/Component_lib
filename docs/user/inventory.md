# 元件与库存

## 元件库存：查找和维护资料

**元件库存** 页面用于查看库存及其完整资料。可按名称、编号等搜索，使用类别、品牌、封装筛选，并按表头排序。双击普通单元格可原位编辑，点击其他位置会保存，按 `Esc` 取消；商品和数据手册单元格双击后用默认浏览器打开。

当前表格包含名称、别名、立创编号、制造商料号、自定义编号、类别、品牌、封装、类别参数、库存、单价、购买日期、订单号、建立/入库/更改日期、位置/仓库、链接和备注。

元件资料和实际数量是两件事：**创建元件不等于入库**；真正入库后才会产生库存批次和流水。

## 入库

1. 在 **入库** 页面选择已有元件，或填写新名称建立元件。
2. 选择一个具体仓库；按需填写单价、采购信息及备注。
3. 输入正整数数量并确认。
4. 回到 **元件库存** 核对数量与位置。

每次入库形成一个批次；同一元件可以分批次、跨仓库存放。

选择已有元件后，界面会自动填入已保存资料。确认入库时，当前表单中的修改会同时更新该元件，不再有额外的“保存修改”开关。“类别参数”前的对号仅用于展开或收起参数区，不会清空其中数据。

## 出库

1. 打开 **出库**，输入名称或编号后再从搜索结果选中元件。
2. 页面会列出该元件真实有库存的仓库及可用数量。
3. 选择仓库、填写数量并提交；如果库存不足会被拒绝。

出库按 FIFO（先入先出）从批次扣减。系统会检查剩余量，不会让数量变成负数。

## 库存流水与错误更正

在 **库存流水** 查看历史操作。已提交的流水不会直接删除；如果做错，可通过适用的**反向冲销**功能更正，冲销也留下记录。请确认冲销影响的整组操作以及当前库存是否满足反向处理条件。

转移仓库、盘点调整和事务冲销也由业务层支持；部分操作主要通过 [本机 API](../developer/api.md) 提供，不应假定所有操作都在桌面主导航中有单独页面。

## 删除元件

没有引用的元件可以删除；已有历史但库存为零的元件会安全归档以保留流水；存在库存的元件不可直接删除。操作前先检查实际库存和历史引用。
