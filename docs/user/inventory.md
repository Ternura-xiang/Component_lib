# 元件与库存

## 查找和维护元件资料

在 **元件库存** 可按名称或编号搜索。类别、品牌和封装下拉选项会随其他条件联动。勾选 **日期范围** 后，可按购买、入库、建立或最后更改日期筛选。右键选择 **查看详细信息** 打开只读资料，选择 **完整编辑** 修改元件资料。类别参数可用三角箭头展开。

双击可编辑单元格可直接修改，移开焦点保存，按 `Esc` 取消。打开链接请用右键菜单中的 **打开商品链接** 或 **打开数据手册**。

同一元件在同一仓库的多笔入库也会分别显示。**批次库存** 是当前行的剩余数量，**总库存** 是该元件在全部仓库的余量，同一元件的各批次行会显示相同的总数。使用订单号、购买日期、入库日期和批次号区分不同采购。批次单价和购买日期保留当次入库记录。

**购入价格** 显示元件采购参数中的购入单价。查看当前批次入库时记录的价格，请看同一行的 **单价**。

页面顶部可把当前筛选结果导出为 Excel 或 CSV。详细字段和价值口径见 [导出与统计](exports-statistics.md)。

点击 **补充资料 → 从立创商城** 可指定范围和最大元件数。连续商品页至少间隔 30 秒，随后可点击 **读取下一项**。遇到登录、验证或加载失败时退出补充窗口并弹出提示。为避免封IP风险请勿一次进行过多请求。

点击 **补充资料 → 从文件** 可选择订单网页或 XLS 物料明细对账单。程序按立创编号匹配已有元件，预览可补齐的空白字段，确认后写入元件资料。同一编号出现多次时，每个字段优先使用日期较新的订单值。

**设置 → 资料匹配** 提供全局的 **启用从立创商城更新** 开关。关闭后，库存、入库和订单预览中的商城更新入口隐藏，库存和订单预览也会隐藏资料匹配列。正在运行的后台匹配会取消。

勾选 **启用商城后台自动匹配** 后，可在设置中查看累计尝试次数、成功次数和失败原因。

创建元件后，通过入库确认生成库存批次和流水。

## 批量变更仓库

1. 在 **元件库存** 选择要移动的批次。按住 `Ctrl` 左键点击可多选。
2. 点击顶部或右键菜单中的 **变更仓库**，也可在库存表格中按 `Ctrl+M`。
3. 先选目标位置，再选该位置下的仓库。核对批次数和件数后点击 **确认移库**。所选批次的全部余量一次移入目标仓库，已在目标仓库的批次保持原位。

移库保留批次的订单号、采购日期、原入库时间和单价。若预览后库存已变动，整组移库会回滚。完成后可在 **库存流水** 展开查看移出和移入记录。

## 入库

1. 在 **入库** 页面选择已有元件，或填写新名称建立元件。
2. 选择一个具体仓库；按需填写单价、采购信息及备注。
3. 输入正整数数量并确认。
4. 回到 **元件库存** 核对数量与位置。

每次入库形成一个批次；同一元件可以分批次、跨仓库存放。

非立创物料可在入库时填写外部制作的批次二维码，格式固定为 `CL` 加十位数字，
例如 `CL0000000001`。该编号全库唯一；不填写时仍可正常入库，但之后不能通过二维码
定位这个批次。扫描立创袋贴入库时，程序使用袋贴中的订单号和立创编号建立批次关系。

选择已有元件后，界面会自动填入已保存资料，确认入库时同时保存表单中的元件修改。点击「类别参数」前的三角箭头可展开或收起参数。

## 出库

1. 打开 **出库**，输入名称或编号后再从搜索结果选中元件。
2. 页面会列出该元件真实有库存的仓库及可用数量。
3. 选择仓库、填写数量并提交。仓库留空时可按 FIFO 跨仓库出库。

出库按 FIFO（先入先出）从批次扣减。系统会检查剩余量，不会让数量变成负数。

也可以在出库页打开摄像头，或粘贴二维码原文。立创袋贴通过订单号和立创编号定位，
自定义物料通过 `CL` 编号定位。识别后程序显示批次和仓库余量并预填全部剩余数量；
在点击“确认出库”前不会修改库存，数量可以改小。扫码出库只扣减识别到的批次。

## 库存流水与错误更正

在 **库存流水** 可按类型、仓库和日期范围筛选，也可搜索元件名称、料号、订单号或备注。含多条流水的事务组可点击左侧箭头查看明细。**导出流水** 将筛选命中的所有明细保存为 Excel 或 CSV，包含折叠的明细。需要盘点调整或冲销时，可使用 [本机 API](../developer/api.md)。

## 删除元件

没有引用的元件可以删除；已有历史但库存为零的元件会安全归档以保留流水；存在库存的元件不可直接删除。操作前先检查实际库存和历史引用。
