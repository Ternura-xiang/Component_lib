# 导出与统计

## 导出库存

在 **元件库存** 页面设置名称、类别、品牌或封装筛选，再点击 **导出 Excel** 或 **导出 CSV**。导出使用当前筛选命中的元件，清空筛选即可导出全部活动元件。零库存元件也会保留，仓库字段为空。

- Excel 包含“概览”“库存明细”“分库统计”“分类统计”四张工作表，保留原生数值、筛选表头和冻结首行。
- CSV 只包含库存明细，采用带 BOM 的 UTF-8 编码，便于 Windows Excel 直接识别中文。
- 导出明细按元件和仓库汇总余量。界面中的同仓库批次行会合并为一条导出记录。

## 查看统计

侧栏 **统计** 页面展示：

- 活动元件种类数和当前库存总件数；
- 每个位置/仓库的元件种类、库存件数和价值；
- 每个元件类别的元件种类、库存件数和价值；
- 未设置类别的元件归入“未分类”。

## 价值口径

库存价值按每个剩余批次计算：优先使用该批次入库时的实际单价；批次没有单价时，回退到元件资料中的当前单价。两处都没有价格的库存不会按零价值冒充已定价库存，而是单独计入“未定价件数”。因此“库存估值”只代表有价格依据的部分。
