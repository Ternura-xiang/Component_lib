# 位置与仓库

在桌面程序中，**位置**是上一级区域，**仓库**是实际放置元件的细分地点。例如：

```text
位置：实验室
├─ 仓库：电阻抽屉
├─ 仓库：电容抽屉
└─ 仓库：开发板收纳箱
```

进入左侧 **位置与仓库**，新增位置后，可在其下新增仓库。双击名称或备注可就地修改，右键菜单提供完整编辑和删除。

系统为每个仓库分配色标。在表格中右键点击该仓库并选择 **更改仓库颜色** 即可修改。库存、入库与出库、BOM、流水、统计和配套安卓端显示同一仓库时会使用这个色标。

需要移动现有库存时，在 **元件库存** 选择实际批次并执行 **变更仓库**。具体步骤见[批量变更仓库](inventory.md#批量变更仓库)。

## 仓库推荐

导入立创订单时，程序可以根据元件类别、存放名称及人工优先级提出仓库建议。

- 点击 **配置整体仓库优先级** 设置所有类别的默认顺序，数字越小越优先。
- 从右键菜单选择 **配置元件类别仓库优先级**，为指定类别设置优先顺序。

推荐只是默认值，订单预览时仍可为每一行独立选择仓库。仓库名中含“电阻”“RLC”等词可能影响推荐，但不保证每次都正确；提交前检查。

## 删除约束

- 位置下还有仓库时，不能删除该位置。
- 仓库若仍有库存批次或流水引用，不能直接删除。
- 建议优先改名或整理历史，而不是删除已经使用过的存放记录。

**开发者注意**：界面称为“位置 → 仓库”，旧 API/数据库使用 `warehouses` 表示上级位置、`locations` 表示具体仓库；字段命名为了兼容性没有同步改名。详见 [数据层](../developer/database.md)。
