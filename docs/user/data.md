# 数据位置、备份与恢复

## 数据保存在哪里

应用优先复用已有的 `inventory.db`。默认数据目录：

| 系统 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\local.component-library.app` |
| Linux | `$XDG_DATA_HOME/local.component-library.app`，未设置时为 `~/.local/share/local.component-library.app` |

目录中包含库存数据库、API 令牌和轮换日志 `logs/component-library.log`。局域网证书及私钥存放在 `connection/`，请勿分享。安卓会把操作命令和入库照片发送至已配对电脑，库存和 OCR 均在电脑处理。

## 创建备份

进入 **设置 → 备份与恢复**，选择备份目录并创建 SQLite 在线快照。程序会为快照生成 SHA-256 校验信息；建议将备份复制到另一个磁盘，特别是在大量导入订单或升级程序前。

库存操作确认后立即保存到 SQLite。勾选 **启用自动备份** 后，可设置备份间隔和保留份数，默认每 10 分钟备份并保留 7 份。首次启用时如果暂无自动备份，会先创建一份。应用重新启动时若已超过设定间隔，会补做一次。自动快照保存在数据目录的 `backups/automatic/`，成功创建新快照后按保留份数轮换。

## 恢复备份

在 **设置 → 备份与恢复** 选择备份文件，或点击 **从自动备份恢复** 进入自动快照目录。程序先做 SQLite 完整性检查，并核对已有的 SHA-256 文件。重启后应用替换数据库前会保存 `inventory.before-restore.db`。

## 清空数据

在 **设置 → 备份与恢复** 点击 **清空数据并在重启后重置**，输入大写 `YES` 确认。下次启动会初始化空库。重置前的数据库可从数据目录选取 `inventory.before-restore.db` 恢复。

## 常见问题

| 现象 | 处理建议 |
| --- | --- |
| 程序提示已运行 | 检查是否有另一实例；应用使用单实例锁 |
| 端口 `17635` 被占用 | 关闭占用该端口的程序后重启；程序需要启动本机 API |
| 安卓无法连接电脑 | 确认两端处于同一局域网，检查桌面防火墙是否允许局域网访问 HTTPS 端口 `17636`，再检查配对状态 |
| 摄像头打不开 | 检查权限、Qt Multimedia/GStreamer；可暂用照片导入 |
| OCR 不可用 | 检查随包模型是否存在及模型状态，参考 [识别文档](../developer/recognition.md) |
| 订单无法解析 | 检索后等待商品明细显示，展开所需商品，以「网页，全部」重新保存 HTML 后导入 |
| 删除操作被拒绝 | 检查库存与历史关联，参见 [元件与库存](inventory.md) |

**不要直接用外部 SQLite 编辑器改库存数量**，会绕过批次和流水约束。集成程序应使用 [本机 API](../developer/api.md)。
