# 快速开始：完成第一笔入库

## 1. 启动程序

使用 Python 3.12 和 `uv`，在项目根目录运行：

```bash
uv sync
uv run component-library
```

若没有 `uv`，可改用：

```bash
python3.12 -m venv .venv
# Linux/macOS
.venv/bin/python -m pip install -e .
.venv/bin/python -m component_library
# Windows 可将 .venv/bin/python 换为 .venv\Scripts\python.exe
```

Linux 上 Qt 摄像头/内嵌浏览器需要相应系统组件；不影响手工库存功能的设计目标。

## 2. 创建存放位置

进入左侧 **位置与仓库**。先创建一个“位置”（例如 `零件柜`），再在它下面创建一个具体“仓库”（例如 `A1 抽屉`）。系统中的两级关系是：

```text
位置：零件柜
  └─ 仓库：A1 抽屉
```

**入库要选择的是具体仓库**，不能只选上级位置。后续可以在这一页调整名称、备注和仓库优先级。

## 3. 建立元件并入库

进入 **入库**：填写或选择元件名称、类别及必要资料；不存在的名称/类别可以新建。选择刚才的仓库，填入正整数数量（例如 100），确认提交。可以按需补充品牌、封装、价格等字段。

进入 **元件库存** 检查该元件是否出现，以及数量和存放仓库是否正确。

## 4. 验证一次出库

进入 **出库**，搜索已入库的元件，选择有库存的仓库，输入不超过可用量的整数数量，提交后回到 **元件库存** 查看余额。可以在 **库存流水** 查到本次操作。

## 下一步

有真实元件袋贴时试试 [扫码识别](scanning.md)；需要从购买记录批量补充库存时阅读 [商城与订单](imports.md)；按项目物料清单领料时阅读 [BOM](bom.md)。

首次录入少量真实元件后，建议立即在 **设置 → 备份与恢复** 创建一次备份。详见 [数据与备份](data.md)。
