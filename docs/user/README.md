# 用户指南

这里面向只想使用程序管理元件的人，不要求了解 Python 或数据库。

建议首次按以下顺序：**[启动与初次入库](quick-start.md) → [位置与仓库](storage.md) → [元件与库存](inventory.md)**。熟悉基本库存操作后，再使用自动化导入。

| 你想做什么 | 文档 |
| --- | --- |
| 第一次运行，创建第一个元件并入库 | [快速开始](quick-start.md) |
| 搜索、维护元件、入库、出库、查看流水 | [元件与库存](inventory.md) |
| 规划抽屉、料盒或存放区域 | [位置与仓库](storage.md) |
| 通过摄像头或照片识别袋贴 | [扫码识别](scanning.md) |
| 从立创商品页补充信息，导入已保存的订单 | [商城与订单](imports.md) |
| 根据 BOM 检查缺料并批量出库 | [BOM](bom.md) |
| 找到数据文件、备份、恢复、故障排查 | [数据与备份](data.md) |

**共同原则**：识别或导入得到的是草稿。检查元件、数量、仓库后，明确提交才会改变库存；数量为整数，不能出成负库存。

返回 [项目首页](../../README.md)；参与开发请阅读 [开发者指南](../developer/README.md)。
