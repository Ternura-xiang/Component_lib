# 商城资料与订单导入

程序提供两种**不同用途**的商城相关工作流：为单个元件补资料，以及从保存的订单文件批量入库。

## 单个商品资料：辅助填写

在 **入库** 页面可打开立创商城的临时内嵌浏览器，由用户自行检索并明确确认**当前商品详情页**。程序解析当前页面已有的产品基本资料和“商品参数”表格，不把并列的“替代料”或“买了又买”作为参数。剪贴板导入作为备用路径。

确认窗口会显示现有值、商城值和最终值。商城资料默认**全部勾选**，包括封装、品牌、类别及所有商品参数；如果不希望覆盖某个现有值，必须在确认前取消该行对号。折叠元件详情不会取消隐藏字段，点击“确认资料”只更新草稿，最后仍需点击“确认入库”。

该方式不是自动批量爬取商城，也不需要在程序中登录商城。内嵌浏览器使用不持久化的临时会话，关闭时清理 Cookie 和内存缓存；不会下载页面文件。网页资料可能缺失或发生变化，尤其应确认型号、封装和单位。

## 导入已保存的立创订单

1. 在浏览器登录立创商城并检索订单。等订单和商品明细显示后，展开需要的「查看全部商品」，用浏览器的 **网页，全部** 保存。可直接选择保存得到的 HTML，也可选择包含该页面的 ZIP。
2. 在 **入库 → 订单导入** 点击 **选择订单压缩包或页面**。程序从本地文件读取商品并自动剔除已取消或关闭的订单。若提示页面缺少明细，回到浏览器确认商品已显示，再重新保存。
3. 解析时可查看当前订单日期、元件和已解析数量。预览仅显示尚未导入的商品，每批最多 1000 条。完成本批后，可重新选择同一文件继续处理剩余商品。
4. 检查预览中的型号、数量、类别、品牌、商品链接及逐行仓库。未导入行默认勾选，可取消不需要的行，双击修改可编辑单元格，或用右键 **完整编辑**。
5. 如需从商品详情页补充资料，点击 **自动匹配并补充资料** 并确认所选字段。使用订单 HTML 中的资料即可直接提交入库。
6. 点击 **确认勾选项入库** 并在确认窗口同意，再到 **元件库存** 和 **库存流水** 核对结果。解析、预览和资料匹配阶段均为草稿操作。

同一订单号与立创编号组成的键用于跳过已入库商品。选中行在同一个数据库事务中提交，发生错误时整批回滚。库存表按批次显示订单号和购买日期。普通入库表单也可填写「立创订单号」，用于关联立创袋贴批次。

## 隐私与边界

订单解析处理本地保存的静态页面，不执行页面脚本，不会保存联系人、收货和物流详情。公开网页元数据读取功能有额外访问限制；**不要用它批量抓取或绕过站点访问政策**。

若列表中某行匹配了错误的已有元件，请在提交前更正；导入后的改动会产生真实库存流水，无法只靠重新预览撤回。
