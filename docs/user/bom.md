# BOM 批量出库

BOM 功能适用于按项目清单统一领料：先读取文件，预览元件匹配和库存缺口，再提交。

## 支持的文件与入口

支持 **CSV、XLSX**，包括立创 EDA 标准版常见的 UTF-16 制表符 CSV，以及专业版
导出的 CSV/XLSX。程序自动识别 UTF-8、UTF-16、GB18030 和逗号、制表符、分号；
XLSX 有多个工作表时会要求选择。入口在左侧 **出库** 页面内。仓库内还提供示例文件
[`examples/example-bom.csv`](../../examples/example-bom.csv)。

程序会识别 Quantity、Comment/Value、Designator、Footprint、Manufacturer Part、
Supplier Part 及对应中文表头。匹配优先使用已确认映射和物料编号，再综合规格、封装、
品牌与名称；只有高置信且无冲突的候选会自动选中。

## 操作步骤

1. 从 **出库 → BOM** 选择文件。
2. 使用第一列勾选本次需要出库的 BOM 行；未勾选行不计入需求或缺料。
3. 核对候选匹配、数量与缺料预览。缺料行整行显示为红色。
4. 候选框可直接输入名称、类别、品牌、封装、立创编号或制造商料号筛选并改选。
5. 查看“推荐仓库”，再逐行选择具体仓库，或在表格上方选择位置和仓库后应用到已勾选行。指定后，缺料和取货只按所选仓库计算。项目名称默认从文件名提取，可在创建任务前修改。
6. 只在所有已选行的匹配和库存量都正确时，创建取货任务。
7. 按“位置 → 仓库”分组取货；可以逐项打钩，也可以在电脑或已配对手机上扫描批次二维码并填写本次数量。
8. 全部需求确认后执行原子出库。

## 规则

- 候选并不等于确认匹配；存在歧义时不应静默选中。
- 人工选择可以保存为该 BOM 物料指纹的映射，下次优先复用；数量和行号不参与指纹。
- 同一库存元件在 BOM 中出现多行时按累计需求检查缺料。
- 桌面创建取货任务前，每条勾选行都需要选定具体仓库。推荐按类别优先级、整体优先级和现有库存计算。
- 创建取货任务不会扣库存；最终提交仍是**原子操作**。提交前库存发生变化时，任务会进入“阻塞”状态，不会部分扣库。
- 扫描到无直接需求的物料时，只显示可解释的替代候选；必须由用户选择目标需求并确认，程序不会自动接受替代料。
- 出库仍遵循 FIFO 与禁止负库存规则。

BOM 预览不修改库存。如果只想查缺料，可停留在预览阶段。
