# BOM 批量出库

BOM 功能适用于按项目清单统一领料：先读取文件，预览元件匹配和库存缺口，再提交。

## 支持的文件与入口

支持 **CSV、XLSX**。准备包含元件名称或编号及数量的表格，入口在左侧 **出库** 页面内。仓库内还提供示例文件 [`examples/example-bom.csv`](../../examples/example-bom.csv)。

程序会尝试识别常见中英文表头；尽量提供立创编号或制造商料号，通常比仅靠自由文本名称更可靠。

## 操作步骤

1. 从 **出库 → BOM** 选择文件。
2. 核对解析行、候选匹配、数量与缺料预览。
3. 重点检查同名不同规格、多个候选或没有找到元件的行。
4. 只在所有行的匹配和库存量都正确时，确认提交。

## 规则

- 候选并不等于确认匹配；存在歧义时不应静默选中。
- BOM 出库是**原子操作**：所有提交行成功才会扣库存，任意一行缺料或校验失败则整体回滚。
- 出库仍遵循 FIFO 与禁止负库存规则。

BOM 预览不修改库存。如果只想查缺料，可停留在预览阶段。
