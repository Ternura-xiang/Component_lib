# 元件库 v0.8.9 发行说明

v0.8.9 重点改进摄像头扫码、批次出库、入库导航和操作后的表单状态。

## 主要变更

- 出库扫描仅识别 QR Code，忽略袋贴上的物流一维码，并持续显示批次和库存匹配结果。
- 修复 PySide6 6.12 摄像头帧 PNG 编码及 zxing-cpp 2.3 默认参数兼容问题。
- 扫描/图片识别移入“入库”子页面，自定义批次二维码可从入库表单直接调起摄像头。
- 移除剪贴板商城导入和 OCR 样本主页面，精简侧边栏。
- 设置页拆分为连接信息、备份与恢复、关于三个选项卡。
- 入库和出库成功后统一清理可重复提交的参数；离开扫描入库时自动关闭摄像头。
- 元件库存右键菜单增加删除操作，仍由数据库层拒绝删除有库存的元件。

## 升级说明

升级前建议在 **设置 → 备份与恢复** 创建数据库快照。本版本保持现有 SQLite 数据和 API 兼容性。
