# 元件库 v0.8.8 发行说明

发布日期：2026-11-04

v0.8.8 是一个面向个人和小型实验室的 **1.0 前预览版**。这个版本已形成从元件录入、实物定位、入出库到流水追踪的完整本地工作流，并加入袋贴 OCR、立创商品资料确认、订单导入和 BOM 出库。

> 升级前请先在“设置与备份”中创建数据库快照。本版本仍属于 1.0 前阶段，建议保留可回退的 `inventory.db` 备份。

## 版本亮点

- 完全使用 Python 3.12 + PySide6 的跨平台桌面架构，不依赖 Rust、Tauri、React 或 Node.js。
- SQLite 本地库存、批次、FIFO、禁止负库存、冲销、备份和恢复工作流已可用。
- 摄像头或图片均可执行离线 OCR；文字识别是主流程，二维码/条码用于交叉校验。
- 入库页可从匿名临时内嵌浏览器选择立创商品，并将商品参数作为可编辑草稿。
- 可离线导入用户保存的立创订单 ZIP/HTML/MHTML，逐行选择仓库并原子入库。
- 支持 CSV/XLSX BOM 匹配预览、缺料检查和原子出库。
- 桌面应用运行时提供带 Bearer Token 和幂等键的本机 `/api/v1`。

## 主要功能

### 元件、位置与库存

- 按名称、别名、立创编号、制造商料号、品牌、封装等内容搜索元件。
- 支持类别、品牌、封装过滤，列排序，原位编辑，商品与数据手册链接。
- 使用“位置 → 仓库”两级模型表达实际零件柜、抽屉或料盒。
- 可为全部元件或指定类别配置仓库推荐优先级。
- 库存数量统一为整数；已有库存或历史引用会限制直接删除。

### 入库与出库

- 元件名称与类别提供可输入、即时过滤的下拉列表。
- 选择已有元件时自动填充资料；确认入库会同时保存当前表单修改。
- 位置和仓库分开选择，只显示当前位置下的仓库。
- 元件类别可定义公共参数列表；“类别参数”对号用于展开或收起参数区。
- 出库按输入内容搜索元件，只列出实际有库存的仓库，再按 FIFO 扣减批次。

### 袋贴文字识别

- RapidOCR + ONNX Runtime 在本机执行中英文、数字和符号识别，运行时不下载模型。
- OpenCV 完成图像缩放、画质评估、标签定位、透视矫正、多预处理分支与方向尝试。
- 识别界面显示取景引导、处理状态和 OCR 文字框，并把结果带到入库页确认。
- 已加入实物袋贴字段解析回归用例；低置信、冲突或无法确认的结果不会自动写入库存。

### 立创商品与订单

- 内嵌浏览器使用 Off-the-Record 会话，不读取系统浏览器 Cookie，不保存登录状态或持久缓存。
- 搜索结果的新窗口商品链接会在当前内嵌视图中打开。
- 只解析用户当前选择的商品页；“商品参数”与替代料、推荐商品分开。
- 基础字段和商品参数默认全部勾选应用；已有值需保留时，用户可逐项取消。
- 订单导入默认勾选每行，可取消、原位编辑或从右键打开完整编辑，并为每个元件独立选择仓库。
- 订单号和购买日期会保存至元件资料；通过订单号与立创编号防止重复入库。

### BOM、API 与数据安全

- BOM 匹配优先级：立创编号 → 制造商料号 → 自定义编号 → 名称候选。
- 多行 BOM 和订单导入使用单个 SQLite 事务，发生错误时整体回滚。
- 本机 API 仅监听 `127.0.0.1:17635`，应用关闭后停止；OpenAPI 页面位于 `/docs`。
- 备份使用 SQLite 在线备份 API 并生成 SHA-256；恢复文件先校验，再在下次启动时替换数据库。

## 本版本重点修复

- 修复立创搜索结果使用新窗口时，内嵌浏览器始终停留在搜索页的问题。
- 修复 4 位数立创编号、`STM32F103C8T6` 等型号以及封装的商品页识别。
- 修复“应用到入库表单”按钮无响应、再次选择商品无法覆盖未提交草稿的问题。
- 修复商品参数误包含替代料或“买了又买”区域的问题。
- 修复订单/BOM 子页返回时侧边栏与内容页状态不一致所导致的 UI 堆叠。
- 修复表格原位编辑失去焦点后仍保留输入框，以及取消编辑时未恢复原值的问题。
- 统一普通复选框、表格复选框和类别参数分组框的白底黑框/黑色对号样式。

## 升级说明

1. 关闭正在运行的元件库。
2. 备份当前数据目录中的 `inventory.db`，或先在应用中创建快照。
3. 替换应用程序，不要删除数据目录。
4. 首次启动 v0.8.8 时会执行可重复运行的 SQLite 结构迁移，然后执行完整性检查。
5. 确认元件数量、位置/仓库、类别参数和最近流水正常后，再继续批量入库。

默认数据目录：

- Windows：`%APPDATA%\local.component-library.app`
- Linux：`$XDG_DATA_HOME/local.component-library.app`，未设置时为 `~/.local/share/local.component-library.app`

## 安装与构建

从源码运行：

```bash
uv sync
uv run component-library
```

构建当前平台的 PyInstaller onedir 产物：

```bash
uv sync --extra dev
uv run python tools/build.py
```

构建结果位于 `dist/component-library/`。PyInstaller 不进行跨平台编译：Windows 安装包必须在 Windows 环境构建和验收，Linux 产物也应在目标 Linux 版本验证。

## 已知限制

- Linux 摄像头受 Qt Multimedia、GStreamer、Portal 和桌面环境影响；不可用时请导入照片。
- OCR 使用预训练模型，反光、严重失焦、遮挡或新版式可能降低准确率；识别结果仍必须由用户确认。
- 立创商品页结构变更可能导致字段缺失；应用不会自动登录、绕过验证码、批量遍历或调用私有接口。
- macOS 仅保留兼容设计，本版本没有完成正式打包与验收。
- 本机 API 随桌面应用运行，不是局域网共享或常驻后台服务。
