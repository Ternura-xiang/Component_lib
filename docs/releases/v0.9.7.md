# 元件库 v0.9.7 发行说明

- 库存流水可更正数量、仓库、批次采购资料和关联元件参数。立创订单号使用独立列。更正导致库存不足或与关联流水冲突时，应用回滚更改并显示原因。
- 设置中的立创商城与用户元件资料库按立创大类和子类显示。可直接查看和编辑元件，商城资料的修改经确认保存为用户副本。
- 后台自动匹配每隔 25–35 秒独立抽签，访问概率为 30%。
- 桌面端与安卓端的出库支持 MAX。桌面端新增旧数据规格化和库存流水分组管理，并支持读取立创工业品商品页。
- 库存归零后元件自动移出库存列表，重新入库或撤销出库后再次显示。规格化可根据商品链接和型号补齐空的数据手册地址；商城匹配优先使用已保存的商品链接。
- 日志分为 Debug、Info、Warning 和 Error。最近十分钟保留全部等级，较早的 Info 以上日志持续保留。设置中的调试页支持显示筛选、复制与完整导出。
