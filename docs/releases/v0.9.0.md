# 元件库 v0.9.0 发行说明

v0.9.0 新增可直接用于盘点和分析的库存导出与统计能力。

## 库存导出

- 元件库存页支持把当前搜索、类别、品牌和封装筛选结果导出为 Excel 或 CSV。
- Excel 包含概览、库存明细、分库统计和分类统计四张工作表；CSV 使用 Excel 兼容的 UTF-8 编码。
- 同一元件按实际仓库拆分明细，零库存活动元件仍保留在导出结果中。

## 统计与价值

- 新增“统计”页面，展示元件种类、库存总件数、分库库存和分类库存。
- 库存价值优先使用批次实际单价，缺失时回退到元件当前单价。
- 没有任何价格依据的库存单独报告为未定价件数，避免低估范围不透明。
- 本机 API 新增只读的 `GET /api/v1/statistics`。

## 版本

- 应用、Python 包和 Windows 安装器版本统一更新为 0.9.0。
