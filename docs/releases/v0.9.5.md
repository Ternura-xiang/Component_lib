# 元件库 v0.9.5 发行说明

- 修复桌面端订单解析完成后预览卡住或异常退出的问题。导入时会提示未保存商品明细的页面，并剔除已取消或关闭的订单。
- 库存表按实际入库批次显示仓库、日期和订单，并显示元件总库存。支持按住 `Ctrl` 多选批次，通过右键菜单、顶部按钮或 `Ctrl+M` 批量移库。
- 库存右键可查看只读详情。类别参数展开后可以滚动编辑，保存按钮留在对话框底部。资料补全确认页的元件和字段名称已左对齐。
- 仓库默认分配色标，支持在仓库页面右键修改。配套 Android v1.0.10 同步显示色标，配对时扫到其他二维码会提示并继续取景。
- 更新库存、订单保存、仓库设置、导出与扫码操作说明。
