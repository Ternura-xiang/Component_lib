# 元件库 v0.8.10 发行说明

v0.8.10 重点改进订单导入与库存元件的立创商品资料补全，并减少界面误操作。

## 订单导入

- 订单预览仅显示编号、名称、数量、价格、匹配状态和目标仓库；类别、品牌、封装、描述与链接默认折叠，可用三角形展开。
- 新增“仅匹配未匹配项”“匹配已勾选项”“全部重新匹配”三种自动补全范围。
- 自动逐页读取公开商品详情，读取结果先集中展示；用户可按元件整体或单独字段、商品参数决定是否应用。
- 只有确认入库后才修改库存；详情页补充的动态参数会随订单元件一并保存。

## 库存与入库

- 库存列表显示“已匹配 / 未匹配”状态，右键可对未匹配、当前或全部元件补充资料。
- 从内置商城确认后入库的元件默认标记为已匹配，普通手工编辑不会清除状态。
- 类别、仓库、摄像头等下拉框忽略鼠标滚轮，避免滚动页面时误改选择。
- 可折叠区域统一使用三角形；对号方框只用于选择是否应用变更。

## 设置与版本

- 关于页保留版本、作者和项目说明，移除第三方许可入口。
- 版本号更新为 0.8.10。
